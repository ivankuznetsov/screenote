## [2026-11-15T09:00:00Z] Remove MinIO from CI and scripts

**Action:** Removed the `container-s3` CI job and the ephemeral MinIO container from `script/attachment_object_store_qualification`. The upstream `minio/minio` image is no longer published, and the project uses remote cloud S3.

**Changes:** `container-s3` dropped from `bin/release-validate` required checks, `.github/rulesets/main.json`, the rulesets README, and the release evidence fixture. The `s3` gate in `script/release_test_matrix` is now a manual gate that needs `SCREENOTE_S3_ENDPOINT` and its companions pointing at a real test bucket.

**Pages updated:** `wiki/testing-and-ci.md`, `wiki/gaps.md`.

**Uncertainty:** The S3 contract tests no longer run on pull requests. The removed job also checked that the built image loads `aws-sdk-s3` and `vips`; nothing replaces that check.

## [2026-11-15T09:30:00Z] Pin the Playwright driver for system tests

**Action:** Added `bin/playwright-install` and a driver/client version guard in `test/system/application_system_test_case.rb`. The Stripe checkout browser test hung locally because `npx` resolved a Playwright 1.58 driver from a parent directory while `playwright-ruby-client` 1.61 was bundled.

**Pages updated:** `wiki/testing-and-ci.md`.
